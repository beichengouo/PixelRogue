# 轮舞于星辉尽头 · PixelRogue

基于 **Godot 4.7.2** 的俯视角房间探索与动作肉鸽游戏，支持 Windows 与 Android。当前已发行玩家版本为 **V0.4**；仓库另含尚未重新打包的交互界面统一改造与现有系统精修。

本仓库保存正式源码、运行素材、地图模板及开发工具。它不是横版平台跳跃原型；旧关卡和退役制作资料已移出工作树，历史状态保留在 Git 提交中。

## 当前内容

- 三名可操控角色：希露媞雅、希希芙、伊露雅，各有技能、被动、天赋与角色剧情。
- 可自由行走的星辉回廊营地，提供商店、仓库、委托、出发准备、NPC 对话和稻草人伤害训练。
- 第一关「苏醒林地」与第二关「失名星城」。第一关通关后，全角色解锁第二关，并从营地独立准备出征。
- 章节独立地图、怪物生态、三位首领及剧情；章节首领沿用第 10／20／30 场开放与第 16／26／36 场强制进入的规则。
- 普通、精英、奖励、游戏、商店、酒馆、祭坛、试炼、异闻及 BossRush 等房型。
- 三个装备槽、遗物构筑、传说套装、绑定装备和撤离结算；专属传说单件拥有独立机制，套装部件可互相联动。普通、危险、绝境与浴血四种难度。
- 装备与遗物采用分品质的叙事介绍，新增燃烧、减速、暴击接技能、破盾、击杀回蓝、多目标施法、低魔普攻及站定防护遗物。
- 键盘、鼠标、自动普攻与安卓触屏操作；按键重映射、触控布局调整及减少动效设置。
- 异闻录、旅途回响、成就系统与版本更新公告。
- 玩家交互界面采用半透明毛玻璃与流光；主菜单首页、角色选择和战斗 HUD 保持原设计，三选一奖励卡保留原底板及出现、选择、消散动画。
- 主动技能提供 0.15 秒输入缓冲；敌我目标切换采用距离迟滞，友军空闲游荡后短暂休息，房间阵容按既有波次侧重组合至多四种合法怪物。
- 奖励、背包与商店突出机制和属性变化，背景故事默认折叠；替换装备显示失去的单件或套装效果，重复遗物显示本次机制增益。绑定装备手动出售需确认。
- 出发配装保留部位筛选、选中物品与滚动位置；核对页列明缺项，撤离与死亡结算分别显示金币、折价、入库及损失。

## 启动工程

1. 安装 Godot 4.7.2，克隆本仓库。
2. 在 Godot 项目管理器中导入根目录的 `project.godot`。
3. 等待首次资源导入完成，按 **F5** 启动。

默认入口为 `src/main/game_shell.tscn`，由它进入主菜单、选人、营地及正式冒险。当前使用 Compatibility 渲染器。

命令行启动：

```powershell
godot --path .
```

源码运行会使用正式玩家存档。自动化测试应使用独立测试环境，不要用真实存档初始化测试角色、仓库或出征。

## 默认操作

| 操作 | 默认键位 |
| --- | --- |
| 移动 | W / A / S / D |
| 键盘模式瞄准与普攻 | 方向键 |
| 鼠标模式瞄准与普攻 | 鼠标指向，按住左键连续攻击 |
| 闪避 | Shift |
| 三个小技能 / 大招 | Q / F / G / V |
| 三个药剂槽 | 1 / 2 / 3 |
| 交互 | E |
| 呼唤女神撤离 | H |
| 背包 / 天赋 / 房间地图 | Tab / T / M |
| 暂停 / 返回 | Esc |
| 确认、背包装卸 | 空格；装备也支持双击 |

以游戏「设置 → 按键」显示的当前绑定为准，支持键盘及鼠标按键（含两个侧键），可随时恢复默认。攻击模式仅能在营地或安全房间更换。安卓使用双摇杆与独立按钮，可在设置中调整位置、大小并恢复默认。

安卓三选一奖励轻点整张卡片即可领取，滑动说明仅滚动文本，展开背景故事不会领取奖励。游戏房八星彩票保留每局一次的隐藏 GM 代行彩蛋；开启后可用底部提示旁的“×”立即退出，代行沿用正常资源与战斗规则。

## 地图编辑器

开发入口：`tools/room_editor/room_editor.tscn`。

```powershell
godot --path . res://tools/room_editor/room_editor.tscn -- --room-editor
```

支持地图图层查看、实际碰撞轮廓、外边界、四向出口、出生点和营地设施交互点编辑，以及游戏内验证。验证结果供参考，不阻止开发者保存模板。

工具栏「控制台 / 单位数值」可切换物资发放和基础数值编辑。物资控制台需要手动载入目标存档，发放前显示预览，并将原档备份到工程外；修改前应关闭使用该存档的游戏。单位数值保存至 `data/unit_balance.json`，支持恢复默认，新启动游戏后生效。开发调试工具和地图编辑器均不进入玩家发行包。

营地内按当前绑定的地图键（默认 M）查看实际建筑模型、自己、设施和移动 NPC 的位置与名称。营地背包与仓库独立，仓库试穿仍由训练配置提供。出发准备使用仓库格子与三个装备槽，双击或空格装卸，只有越过大门时才实际扣除携带物资。营地商店购买的装备均为绑定装备，成功撤离后原件返回仓库，战斗死亡仍会损失。

- 内置模板：`assets/room_templates/`。
- 分层场景与运行素材：`assets/room_illustrated/`。
- 开发者保存的自定义模板位于 Godot 用户目录的 `room_templates/` 中，默认优先于同 ID 内置模板。
- 发行前应核对自定义营地模板是否已同步到内置模板；`tools/sync_authoring_templates.py` 提供同步工具，执行前先检查其目标路径。

地图编辑器属于开发工具，不随玩家发行包导出。

## 目录与核心入口

| 目录 | 内容 |
| --- | --- |
| `src/main/` | 启动、场景切换与公共冒险流程 |
| `src/room_mode/` | 俯视战斗、房间图、地图渲染、角色与首领运行时 |
| `src/camp/` | 可交互营地、NPC、引导与训练 |
| `src/ui/` | 玩家界面、菜单、对话、背包、奖励与公告 |
| `src/data/`、`data/` | 章节、物品、技能、天赋、剧情及数值配置 |
| `src/autoload/` | 存档、出征、角色、剧情、音频与界面状态 |
| `src/actors/`、`src/world/` | 当前俯视玩法仍复用的角色、战斗与空间基础接口 |
| `src/room_editor/`、`tools/room_editor/` | 地图及分层素材编辑器 |
| `assets/` | 游戏素材、地图与资源授权资料 |
| `tests/`、`tools/` | 回归验证及开发辅助工具 |

`src/world/` 与部分角色基类仍由当前房间模式继承，不能按目录名当作旧横版文件整体删除。退役物品 ID 等兼容数据也需保留，避免旧存档失效。

## 存档与开发约定

- 项目使用 Godot 自定义用户目录 `Godot/app_userdata/PixelRogue`；Windows 通常位于 `%APPDATA%/Godot/app_userdata/PixelRogue`。
- 账户、仓库与活跃出征保存在 `pixel_rogue_save.json`，剧情记录保存在 `pixel_rogue_story.json`；存档不提交仓库。
- 本地开发工作资料统一放在 `E:/CodexWorkspace/PixelRogue`。独立测试副本、测试存档、日志和归档均在工程目录之外。
- 当前编辑器不因自动化测试而被停止；不录制测试视频。

## 导出玩家版本

`export_presets.cfg` 包含当前 Windows 和 Android 发行预设。自定义模板、SDK、Java 与签名密钥是本机配置，克隆后需在 Godot 导出设置中配置；私钥和密码不属于仓库内容。

导出前核对版本号、章节素材、最新营地模板和资源引用，使用 Release 模板。玩家包排除地图编辑器、测试、制作工具、原稿和文档；规则由导出预设及 `tools/audit_player_export.py` 维护。

```powershell
python tools/audit_player_export.py
```

上述命令只检查资源；添加 `--apply` 才会更新排除规则。导出后应运行 PC 冒烟检查，并校验 Android 的版本、签名和包完整性。
