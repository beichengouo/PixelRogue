# 开篇至第二章小说大纲与角色动作规划

更新：2026-10-26。本文是后续增补修订的统一大纲。章节、事件ID、Boss顺序以现有工程为准；不是新游戏方案，也不把未实现内容写成已实装。设计原文V1.1保持只读，本文吸收其人物动机，采用用户最新的日系轻小说冒险文风。

## 范围与留白

本轮叙事从星辉回廊开篇写到第二章《失名星城》的阶段性收束。**第二章之后留白**：不预设第三章地点、最终敌人、失忆真凶、伊莉丝最终身份或最终结局。以后新增关卡和剧情，在本文原结构中新增或修改，并同步事件映射；不另起一份互相冲突的总纲。

两章结束只证明部分旧经历可以互相印证、旧命令确实被改动。四人不会突然恢复完整记忆，也不会发现“以前早就是恋人”。恋爱取决于现在的相处与明确选择。第四阶段为可选旧影调查，核心理解、共同过去和恋爱推进不能强制要求BossRush。

## 叙述与选项

- 远行采用当前角色第三人称限知视角，允许贴近她的短促内心吐槽、犹豫和小期待。她会先担心水、伤口、饭点、同伴和回程，再讨论抽象道理；不是每个人都说同一套“记录、核对、拒绝、归路”。
- 营地采用契约者“你”的视角。玩家是黑斗篷遮住全身、雌雄莫辨的独立人物，留在回廊准备物资、听取见闻，不附身角色，不凭操作知道所有剧情内心。
- 名词第一次出现由旁白解释用途、可观察现象与限制，再给角色反应。旁白通常一段90—180字，必要时分成有完整意思的两段；对白通常20—60字。不能把一句话拆成四个点击框，也不把一整章背景塞成说明书。
- 危险和探索段以白话、具体行动为主。高潮可以短暂抬高语气，紧接着回到人物眼前的愿望与行动。没有明确愤怒动机，不使用生气表情。
- 有剧情选项时先由角色向玩家提出具体问题，选项是契约者的建议、感受或关系回答；不是让玩家冒充角色自问自答。远行中只在已有安全叙事节点借归航联系短暂传讯，不能借此遥控战斗或共享全部记忆。首次说明这是归航联系的短讯用途，并非新通信玩法。
- 提问之后再显示选项；友好、拒绝、暂缓都有承接对白。选项原有ID、下个事件、奖励、好感、排他与保存事务保留。涉及恋爱先让角色明确询问，不由旁白替玩家选择。

## 人物声线与开篇锚点

| 人物 | 日常说话与思考 | 个人冒险问题 | 两章中可确认的变化 |
|---|---|---|---|
| 契约者 | 先问伤势、吃饭和具体需要；可以打趣，不能全知 | 失去共同记忆后怎样重新认识她们 | 从只记收获，变成也愿意听失败、矛盾和日常 |
| 希希芙 | 起初认真、略紧张，熟悉后会小声吐槽；谈伙伴时话变多 | 会不会因为“不够有用”而被留下 | 学会直接说希望有人等，不拿契约换陪伴 |
| 希露媞雅 | 温柔有条理，遇危险能明确制止；内心常忙着照顾别人 | 不救下所有人是否就算失败 | 会先照顾自己，也会主动提出休息和陪伴的愿望 |
| 伊露雅 | 简短、观察敏锐，偶尔干脆地戳破借口；内心有生活感 | 接受同行是否就再不能自由离开 | 愿意留下自己的去向，也相信有人会等而不催 |
| 伊莉丝 | 能解释的直接解释；不知道就说不知道，偶有疲倦与幽默 | 能接回旅人，却不能保证每次安全或替人决定 | 接受大家帮忙，不用神秘话遮掩能力边界 |

**小灵**是希希芙自愿同行的骸灵伙伴，平时借小骷髅形体活动，用敲击和动作回答。不是活人尸体被她操控，不是黑晶牵动的敌对骷髅；魔力形体散去不等于灵体被毁灭。它的更早来历仍不清楚，不能替失忆的四人提供万能答案。开篇先解释“骸灵”和双方自愿的关系，再以它敲错节拍、认真看行囊等小动作呈现相处。幽灯是另一位灵体伙伴，不与小灵混为一人。旧称“小扣”统一停用，内部召唤／成就ID不变。

## 序幕：四只杯子

回廊是一处能让旅人休整、重新出发的营地。契约者与三位伙伴都记得名字和本领，却想不起个人经历以及为何相识。伊莉丝先说明这个共同现状，不替空白编造答案。温阮摆好四只杯子，三人下意识留出各自习惯的位置；她们自己也说不清为什么。熟悉感只当伏笔，不当已经恢复的记忆。

营地引导介绍归航灯、仓库、准备、独立训练入口。解释黑晶会保存并拼接声音与动作；再熟悉的呼唤也不能直接当真人。四人的实际目标是：先去林地找与旧物相似的护送路标，确认可安全返回的道路，带回能够当面讨论的线索。死亡损失本局尚未带回物资，旧仓库不受损；三阶段击败Boss不自动入库。

三人开篇各有独立一幕。希希芙先介绍小灵，担心它吓到你；希露媞雅检查大家的水杯，却忘了自己的茶；伊露雅想先看路况，嘴上嫌行囊多，仍把备用绷带收好。她们分别问你第一趟希望注意什么，再出发。相同关卡不必写成三人同时战斗。

## 第一章：苏醒林地

### 第一阶段：先把路找回来

对应`intro_wake、cp_10、cp_20、forest_king_before、cp_30`。

1. 出征者来到路标边，发现“护送通过”被黑晶遮成了“留在这里”。旁白说明晶丝像传递旧指令的线路，敌人仍在做任务，只是任务被改错。
2. 废岗亭留有孩子画的箭头、名单和修补披风。人物不是立刻谈宏大命题：希希芙先防止小灵把披风背走；希露媞雅先查看遗留绷带；伊露雅找到能继续走的脚印。
3. 林之骸王是曾经的护送队长，如今被晶结控制。战斗目标是让门徽停止封路；非人Boss通过动作和记录交代，不给它新增对话头像。
4. 骸王倒下后道路恢复，得到下一站的方向。人物第一次感到调查真的有用，也会想到回廊的热饭、没喝完的茶或等她的人。记忆线索保留“像见过”的程度。

### 第二阶段：熟悉的声音未必是本人

对应`cp_40、cp_50、forest_mage_before、cp_60`。

1. 晶体播放许多被截去后半句的求救。先展示同一声咳嗽和停顿重复，再由旁白解释“回声”是播放记录，不是对方正等在深处。
2. 三人的不同弱点被勾起：希希芙担心听漏伙伴；希露媞雅几乎想答应每一声求救；伊露雅听到似乎来自故乡的指路声。内心给出短暂冲动，再用观察与同伴习惯找出矛盾。
3. 晶化术士过去保存求救记录，失控后将所有请求维持为永远有效。击破控制晶结，救出的不是一组抽象“声音”，而是让保留的讯息能停止重复。
4. 晶片编号指向失名星城。人物在回营事件里主动讲述自己差点被骗的地方，契约者可以听完、安慰或提出办法；不能默认玩家在场见证全部内心。

### 第三阶段：一起走，也要能停下来

对应`cp_70、cp_80、cp_90、forest_tide_before、cp_100`。

1. 水流停住、旧灌渠倒流、树根把出口缠紧。先让玩家看清生态受损，再解释潮汐之根原本用于保护避难水源。
2. 旧指令缺少停止条件，树根不断把“保护所有树”理解成“谁也不能变化”。三人各有明确行动：希希芙让小灵侦察安全侧路，希露媞雅留出能退后的空间，伊露雅辨认仍有生命的根，避开误伤。
3. 战胜潮汐之根，水和道路恢复。得到完整路线编号和几处与旧物对应的细节；第一章问题解决到“林地可以离开”，不是世界真相已揭晓。
4. 正常撤离与可选第四阶段都不带道德评判。只有成功撤离物资才入库。归来后有不同角色的生活场景，以具体对话消化调查成果。

### 可选第四阶段

`stage_echo_entry`解释旧影只是残存记录，不是已解放者再被关回。可获得额外可核对资料，不垄断主线结论或恋爱线。失败照常损失整趟未带回物资，不用新剧情掩盖风险。

## 章间：旧驿站的一场雨

现有好感事件按0／20／50／100／200及原条件推进。先恢复生活细节：四人曾在驿站躲雨，谁坐门边，谁画了很不像的伙伴，谁为披风补过针脚。不同人可记得不同部分；没有人一次讲出完整旧史。

低好感谈生活与不安；中好感愿意分享难堪和依靠；高好感由角色明确询问是否更亲近、是否交往。友情和暂缓仍有完整回应。既往熟识不自动变成恋人，找回记忆也不替现在签约。旧事件已看过的玩家保留既有回顾入口，不重发奖励或清空关系。

## 第二章：失名星城

### 第一阶段：能进城，却不能出城

对应`city_entry、city_clue_2、city_clue_4、city_sephra_before、city_sephra_after`。

1. 城门编号与林地晶片一致，四人决定查原始登记。记录官维蕾娜先以投影出现，直接说明本人在书馆，不能借投影替人开门。
2. 街景像有人刚离开：空桌、未收的杯子、重复的日期。旁白解释“登记”“归档”是旧日护送登记和资料保存，不是神秘的命运法则。
3. 塞芙菈仍把每个离城者当成走失者送回住所。战前先交涉，发现其门印被控制再战斗；解放后让她休息、检查巡卫命令，不写成永久死亡。
4. 通过安全节点，角色问契约者最在意哪条线索。建议帮助她整理思路，她仍自主判断眼前危险。

### 第二阶段：承认做错，才有办法修好

对应`city_verena_before、city_verena_after`。

1. 维蕾娜承认参与加过保护档案的限制，旧意图可以理解，实际后果却不能被抹掉。人物会先救眼前受控的人，而不是逼她立即说出终极真相。
2. 接管发生时，她努力说完躲避提醒；战斗解除控制，不毁掉所有名册。三人的回应分别落在朋友可否离开、照顾者可否求助、护送者可否改正道路上。
3. 战后原件显示停止条件后来被删，但无署名。明确保留这一证据缺口。她交出能查阅的路线，选择留下更正记录；不是被一句“原谅你”消除责任。

### 第三阶段：过去可以找，今天也得留下

对应`city_nameless_before、city_nameless_after、city_return`。

1. 无名录仪是全城登记装置，能播放旧记录并要求交回现有身份。它声称能恢复过去，不代表它知道或能保证全部真相。
2. 三人都想找回记忆，但拒绝以抹去当下经历为代价。希希芙想到今天自愿跟来的小灵；希露媞雅想到自己终于答应的一次休息；伊露雅想到能自由来回的窗边。高潮可稍有抒情，但回答仍是人物自己的话。
3. 强制回路关闭，居民可修改登记并离城；资料仍可自愿保留。维蕾娜负责修订，塞芙菈重新确认护送职责。此处完成第二章本地冲突。
4. 成功撤离后，四人在回廊把片段与物件放在同一张桌上：他们曾相识、共同经历过一次护送，部分地点和日常吻合；失忆原因、删除者和伊莉丝的全部过去仍未知。
5. 收束在一顿饭或一次约好的闲谈。恋爱可由已有关系进度继续发展，不把角色交给“命中注定”的旧关系。**下一章地点、敌人、转折与最终真相全部留白。**

## 另外两名角色的五段普攻设计（待战斗实装）

只设计，不在素材齐备前替换两人的现有普攻。D为原一发普攻完整伤害基准；攻速缩放全段时间。继续复用原伤害上下文、收据、天赋和装备入口，不复制希希芙三弹扇射。

### 共同制作与验收要求

两套都先完成五段关键姿势设计稿，再绘每段准备／释放／回收／回到下一姿态的独立帧，不能五张摆拍循环。每张运行源图最多4帧，移动版要有脚经过骨盆下方的姿态。普通／传说共享同一身体尺寸、握持方式和动作骨架；服装、头发可摆动，但不能靠摆腰与逐帧缩放制造动画。未实装前不调整现有角色伤害、技能／塔罗联动、存档与成就。后续实装需验证攻速、取消预算、主目标／副目标伤害、装备收据、既有强化优先级与Bot，数值表仅为候选设计，不宣称已平衡。
