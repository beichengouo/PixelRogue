# PixelRogue 世界观、章节主线与契约者关系剧情重构方案 V1.1

> **文档性质**：剧情圣经／叙事策划／角色好感与恋爱线设计／Codex 实装对照稿。  
> **依据**：用户提供《当前剧情与世界观（V0.5 源码整理）》及已讨论的三阶段地图＋可选第四阶段设计。  
> **重要声明**：本文所有新增世界观解释、场景、人物内心、台词与触发条件均为**新设计提案**，不是已经实装的设定。  
> **V1.1 重大修订**：**玩家／契约者是独立存在的叙事人物，具有主观视角和选择权，但没有独立可操控的战斗角色。三名战斗主角并非玩家的化身；玩家与她们拥有好感度及未来恋爱剧情。**
>
> 1.1版本仅为当前文案版本为1.1版本，而非游戏版本，游戏版本仍保持0.5

## 0. 先定清楚：这是一部谁的故事？

**双线叙事**：

1. **远行线（章节主线）**：伊露雅、希露媞雅、希希芙作为可以选择使用的战斗主角，分别面对黑晶、失忆、守护命令及世界崩坏。玩家在游戏操作层面操纵所选角色；**故事里行动、受伤、做出个人判断的是该角色本人**。
2. **归来线（回廊／关系线）**：玩家作为被称为**“契约者”**的独立人物存在，使用“你”的第二人称视角，与她们以及营地居民交谈、协助出征、承诺等待、赠礼、处理关系与探索回廊真相。玩家不具有独立战斗模型，也不需要加入战斗队伍才能在叙事中存在。

两条线因“归航契约”相连，但**契约不是支配**。玩家可以在准备界面选择出征者与装备，这是游戏操作权；故事上必须明确每位主角仍有意愿、主张和拒绝权，不能把她们写成等待玩家命令的工具。

一句话主题：**守护不是留下对方，爱也不是占有对方；真正的约定，是让彼此都拥有归来和离开的权利。**

### 0.1 必须保持的叙事约束

- 玩家 = 契约者；不是伊莉丝，不是第四名隐藏的可操控战斗主角，也不等同当前出征的任何一位主角。
- 角色可与“你”在回廊面对面互动。对“你”的形貌、性别、年龄和过去暂不写死，保留代入空间；不要断言玩家必然没有实体。叙事能用“你递过”“你听见”，却不需要为玩家制作战斗身体。
- 玩家视角可以在远行线看到角色的冒险，但**观察≠时时刻刻通过魔法摄像头监视**。如需解释，在回廊使用短暂的“星辉回响”片段或角色归来后的讲述；不应让远行角色在无人场景对一个不存在的随行玩家持续讲话。
- 恋爱线是后续可主动开启的支线，**好感度不自动等于爱情**，高好感可以保持深厚友情；给予角色表达愿意、不愿意和需要时间的机会。
- 现有好感门槛（0／20／50／100，高好感200送行）可作为迁移参考，但新关系线的实际阈值应以项目系统能力及游玩节奏复核。
- 角色之间有独立关系，不因恋爱线而丧失个人目标。玩家在一局中使用谁，不应剥夺未出征角色在营地的成长机会。

## 1. 统一世界观：将现有设定织成同一条因果链

### 1.1 圣云大陆、旧灾难与“不肯结束的保护”

圣云大陆曾遭受一场年代不详的迁徙灾难。不同地区为防止人们失散，建立过道路守卫、姓名档案、星辉信标与撤离约定。它们本来为了让人**可以找到彼此**而存在。后来，某些记录和命令失去“可以结束”“可以拒绝”的条款：林地的护送变成封锁，星城的保存变成强制归档。

黑晶会保存并模拟声音、动作与记忆碎片；它不是简单的“绝对邪恶之石”，也不是已经证实的世界崩坏始作俑者。它将过去有效的意愿不断复写，使旧命令看起来像永远有效。

**两章共用主题**：旧日的爱与守护，失去被保护者的回应后，就可能成为牢笼。

### 1.2 世界运作的五条规则

**留名**：一个人的名字、声音或某段誓约能成为辨识线索。记录保留当时的事实，却无权规定一个人今后的选择。

**守誓**：护送、守门、疗愈、归档系统执行的持续性职责。拥有停止条件的守誓是守护；被抹去停止条件的守誓会产生悲剧。

**黑晶回声**：将旧命令固化、拼接和模仿的异常记录媒介。它能制造熟悉的声音，但不代表发声者仍持有当年的想法。

**星辉回廊与归航契约**：回廊是相对稳定的归路锚点。伊莉丝能引导与锚点仍有联系的旅人归来，但不能替对方经历战斗，也不能把死亡时遗失的材料一并带回。契约者参与维护归路与远行准备，**不是将三位主角的意志绑在自己身上**。

**生命伤痕**：部分黑晶侵蚀会损伤角色在本局中可维持的生命上限，普通治疗无法抹平；特定星象／塔罗提供有限防护或修复。关于“永久”，指当前出征无法自然恢复，不等于永久删改局外角色基础属性。

### 1.3 明确哪些真相尚未揭晓

| 类型 | 可确定的内容 | 暂不定论的内容 |
|---|---|---|
| 世界历史 | 存在旧灾难与大迁徙；各地旧保护系统失控 | 具体纪年、首场灾难起因、战争全貌 |
| 伊莉丝 | 曾参与星城撤离信标；现在能引导回廊归航 | 她是否是第一个契约者、是否真正神祇、是否知晓最终黑幕 |
| 三名主角 | 有各自的能力、性格、失落记忆和在路上形成的选择 | 失忆前的完整身份与全部旧关系 |
| 契约者 | 是玩家的叙事身份，参与回廊关系和出征准备 | 其起源、为何能与回廊建立特别联系；可作为长期个人谜团 |
| 黑晶 | 会复写记忆／命令，并造成现实侵蚀 | 是否有统一意志，或只是更大灾难的症状 |

**叙事纪律**：老台词说“世界每次重置”“伊莉丝签了第一个约定”等，只能暂时标注为人物自述或传闻。等第三章及以后有足够证据再决定它们是否属实。

### 1.4 相对时间线

1. **旧灾难发生**：迁徙与失散开始；各地需要保留姓名、道路和归来信号。
2. **保护体系形成**：苏醒林地负责护送与封锁险境，失名星城保存姓名与记忆；伊莉丝曾协助部分撤离信标。
3. **守誓异化**：停止条款损毁或被改写，黑晶放大旧命令，越来越多地方无法允许正常的离开与改变。
4. **星辉回廊维持有限归路**：伊莉丝守望，契约者与之建立联系；玩家如何来到回廊暂不强行解释。
5. **角色相继踏上旅途**：三名主角在不同出征中面对自己的记忆谜团。第一章苏醒林地，第二章失名星城。
6. **逐章解除守誓**：首次通关改变世界的长期状态；再次挑战是新的冒险／残存回声，并非已经解放的角色每次都重新受困。

## 2. 契约者：玩家视角的定位与剧情弧线

### 2.1 角色定位

- **称谓**：“契约者”为伊莉丝及回廊中人对玩家的称呼，可以在未来埋下此称谓不完整的伏笔。
- **叙事视角**：默认第二人称“你”。对话选择由玩家做出；人物反应应真正记住选择，而不只机械加好感。
- **空间定位**：主要活动于星辉回廊与营地；不拥有独立可操控冒险实体。远行时玩家在操作上控制主角，不代表契约者进入了该角色的身体。
- **现实参与**：维护出征约定、记录带回线索、准备物资、询问归来情况、陪伴疲惫的旅人，并在有限时刻通过回廊共鸣感知远方的信号。
- **能力边界**：不能擅自读取旅人的思想、强迫恋爱、改写她们的记忆、撤销死亡风险或在战斗中无代价救援。

### 2.2 契约者自身的成长

| 时期 | 初始误区 | 关键学习 | 对关系线的影响 |
|---|---|---|---|
| 初来回廊 | 以为准备充足就能保证每个人安全 | 承认“担心”与“控制”不同 | 允许角色自己决定何时远行 |
| 第一章前半 | 把归来等同成功 | 理解归来者可以恐惧、失落、沉默 | 不用战利品衡量她的价值 |
| 第一章后半 | 想替对方承担所有危险 | 学会许诺在场，却不能许诺零风险 | 爱的表达先于占有 |
| 第二章 | 害怕记忆缺失会抹除亲密 | 尊重对方修正对自己的认知 | 关系不是一份永远不能撤销的记录 |
| 高好感／恋爱阶段 | 想靠一句承诺锁定明天 | 双方可以重新选择、相互确认 | 恋爱由共同决定，不是好感数字自动兑奖 |

### 2.3 玩家与远行镜头的统一写法

**营地／好感事件**：可以写“你在她身旁坐下”“你把礼物递过去”，因为契约者确实作为叙事人物与角色互动。

**迷宫／战斗事件**：以当前主角的第三人称或第一人称局部视角表现。示例：“希露媞雅将掌心的圣光压低。她知道，回廊里还有人在等她，但这一刻是否继续向前，只能由她自己决定。”

**远征归来事件**：让角色亲口告诉契约者她经历了什么，而不是默认玩家角色全程在场。可以有玩家选择：“先听她说完／询问伤势／先递一杯热茶”。

**剧情解谜**：玩家可以透过营地记录整理多个角色带回的证据，但不直接把多角色的私人记忆当作自己的经历。

### 2.4 关系剧情应有两套独立状态

- **世界／角色共通状态**：章节解锁、线索研究、NPC 请求、远征结果、角色个人成长。
- **玩家与某人的关系状态**：好感度、信任事件是否完成、关系选择（友情／暧昧／恋爱）、专属礼物与邀约、告白回复、送行风格。

不能以 `selected_character == X` 作为唯一的关系进度来源；恋爱进度应当持久保存在营地侧，跨局有效。

## 3. 四位关键人物与三条恋爱线

### 3.1 伊露雅 `ilyua`：自由与允许被等待

**原有形象**：成年精灵、浅绿长发、白兜帽、湖蓝眼睛、藤纹短弓；能通过风和植物辨别异状。

**外在目标**：寻找被黑晶窒息的林木与故乡的痕迹。

**内在矛盾**：她认为“守护故乡”必须独自完成，也担心接受陪伴会让自己背负另一份无法离开的誓言。

**主线成长**：从“我必须一直留下”转变为“我愿意回来，但这应当是我的选择”。

**与契约者的关系主题：留一条不催促的归路。**

她不是轻易说甜言蜜语的人。初期交谈更重视倾听、空间和行动；熟悉以后会为你描述林间风声，分享只有她认得的路标。亲密表现为愿意让你知道她害怕迷路的时刻，而非突然变成依赖型角色。

推荐恋爱核心场景：回廊窗边没有真正的风，她把一枚装有种子的藤环交给你，不要求你永远等，只希望“如果它长出叶子，替我告诉下一次归来的人”。

**恋爱线边界**：不得写成她为了玩家永久舍弃故乡；真正确认关系是两人允许彼此保有各自的路。

### 3.2 希露媞雅 `sylphiette`：无需凭牺牲换取爱

**原有形象**：银发蓝眼、纯白金纹祭袍、圣云发饰、温柔坚定，**没有兜帽或巫师帽**。

**外在目标**：回应林地与星城被困者的祈愿。

**内在矛盾**：把所有人的痛苦看成自己必须承担的义务，害怕不够强大就不值得被等待。

**主线成长**：明白守护需要尊重选择，也需要对自己的生命负责。

**与契约者的关系主题：即使今天没有救下谁，也可以被爱。**

初期她感谢你准备物资，却会把休息推后；中期当你询问她真正需要什么，回答可能是“不必让我一直坚强”；后期她愿意主动表达愿望，而不是只问“我能为你做什么”。

推荐恋爱核心场景：她完成一场长祷后没有继续点灯，只在你旁边坐下。你问她今晚是否还要守望，她说：“如果你愿意，我想先和你一起看灯熄灭。”

**恋爱线边界**：不得将她的祭司职责变成玩家独占的治疗功能，也不要沿用旧文案中与当前人设矛盾的“帽檐／帽带”。

### 3.3 希希芙 `xixifu`：可以不签字的约定

**原有形象**：黑色长发与黑眸的成年魔族少女，外貌接近人类、无角尾，与召唤伙伴平等立约。

**外在目标**：寻找失散伙伴、辨认自己从前的家。

**内在矛盾**：极度害怕被遗忘，容易把“被需要”当成“不会被抛下”的证明。

**主线成长**：学会让契约留白，相信自由选择后的归来，比强制留住更珍贵。

**与契约者的关系主题：不必证明有用，才值得有人等候。**

她会分享幽灯和小扣的趣事，在你忘记一件小事时显得紧张；信任加深以后，她才敢问：“如果我没有带回任何东西，你还愿意听我说话吗？”

推荐恋爱核心场景：她把尚未写完的契约纸放在桌上，你发现最后一行空白。她没有请你签下永远同行，而是说：“明天醒来以后，我可以再来问你一次吗？”

**恋爱线边界**：不要把她对遗弃的恐惧当成玩家可以利用的软弱；成熟关系应鼓励她拥有玩家之外的朋友与生活。

### 3.4 伊莉丝 `iris`：守望而非替人决定

**既有地位**：星辉回廊的引路人，可将符合条件的旅人接回，部分人称其女神；她自称不是真正的神。

**人物弧线**：她既害怕失去归来者，也清楚把旅人留下与黑晶的错误只差一步。她与契约者的关系是主线的思想镜子：你们会讨论“帮她回来”与“要求她回来”究竟有什么区别。

**关系规划**：保留原有伊莉丝好感事件，作为重要的信赖与陪伴线。是否进一步设置其恋爱路线，应与三名主角的恋爱规划分开决定，本版不擅自强制赋予恋爱结局。

### 3.5 维蕾娜与回廊居民

维蕾娜不是纯恶反派：她参与保存规则的修订，受归档命令控制后作为第二章阶段 Boss，被解放后继续承担更正记录的责任。营地姜糖、温阮、布琳娜、艾莉娅、闻铃、希尔薇娅等保留各自商业、疗愈、研究或委托功能，并通过日常小事件让回廊有生活气息。

## 4. 两章主线：每章三阶段＋可选第四阶段

> 以下阶段名为**设计建议**；现有章节正式名称“苏醒林地”“失名星城”保持不变，Boss 顺序以 `ChapterCatalog` 为准。三阶段进度不再依赖固定 10／20／30 波。

### 4.1 第一章《苏醒林地》

**章节表层目标**：穿越被晶丝缠绕的森林，恢复古旧通路，让旅人能够自主离开。

**章节深层问题**：一份“永远保护”的誓言，何时成了对所有人的囚禁？

#### 第一阶段：迷途林缘／林之骸王

- **入口**：玩家在回廊选择出征者后，角色在林缘醒来。先感到陌生而熟悉的生命气息。
- **必见线索**：旧门徽记录着“保护最后一位旅人安全通过”。碑文上的“通过”被黑晶压成模糊的“留下”。
- **可选线索**：守卫名册、孩子画的归家箭头、无主披风；分别呼应三名主角的个人记忆。
- **Boss 原始职责**：林之骸王曾是护送者，守住撤离的最后一扇门。它现在无法区分“保护”与“截留”。
- **战前短对白**：
  - 骸王：“门后没有危险。因为没有人被允许到达门后。”
  - 当前主角回应：“那不是你最初要守护的路。”
- **战后变化**：门徽碎裂，地图的下一阶段入口出现。玩家得知守卫过去保护的是离开的权利，而非门本身。
- **情感回声**：契约者收到此次归来者讲述时，可以选择问她“害怕吗”，而不只是“得到了什么”。

#### 第二阶段：誓言遗址／晶化术士

- **入口**：守卫的门后并非出口，而是被晶体保存下来的无数条旧誓言。
- **必见线索**：晶石能模仿熟人的声音；存在把“愿意帮助”重写为“永不离去”的抄本。
- **可选线索**：伊露雅关于古树旧誓的记忆、希露媞雅缺失的祝祷结束句、希希芙空白契约的逆向镜像。
- **Boss 原始职责**：晶化术士尝试将濒临散失的求救声保存下来，最终把反复播放当成真正的回应。
- **战前短对白**：
  - 晶化术士：“我保存了每一句‘不要走’。所以没有人会离开。”
  - 当前主角：“你有没有保存那些后来愿意告别的人？”
- **战后变化**：封存的声音逐一分离，揭示晶石中混有不属于森林的记录格式，指向失名星城。

#### 第三阶段：沉根湿地／潮汐之根

- **入口**：所有根系都在同一节奏上呼吸，真正的水流却逐渐停止。
- **必见线索**：潮汐之根不断重复“不要丢下任何一株树”，连自身也无法停止。
- **Boss 原始职责**：在旧灾难中把林地与避难水源维系在一起；当保护指令失控，它把整个生态系卷入同一束根结。
- **战前短对白**：
  - 根中回声：“停下，便会失去。”
  - 当前主角：“变化不等于抛弃。活着的树也要有自己的季节。”
- **战后变化**：一片叶子终于自由飘落，林地恢复可离开的道路。开启第二章线索。
- **正常通关选择**：Boss 奖励完成后，玩家作为契约者在归航端确认**安全撤离**，或协助当前主角选择**继续深入残存回声**（特殊第四阶段）。剧情不给撤离者贴上胆怯标签。

#### 可选第四阶段：回声深井／三重旧影 BossRush

- **地图规模**：正常阶段两倍，20～28 间；普通战斗房全部替换成精英战斗房，但仍有商店、酒馆各一间，额外特殊房1～2间。
- **探索要求**：主线路径可控制在约 7～10 间以内，其余房间作为可选探索，避免纯粹拖延。
- **BossRush 解释**：三个已败 Boss 的**留存记录投影**在深层同时重演，不是把先前获释者重新捕获。
- **新信息**：三重守护命令曾从同一份不完整的“归航协议”转录而来，记录中有通往星城的署名痕迹，但缺少原始签署者，不能提前指认伊莉丝有罪。
- **胜利**：可以撤离并获得第四阶段独立成就与高价值奖励结算资格。**材料必须实际成功撤离后入库；进入第四阶段死亡会损失整局尚未带回材料。**

### 4.2 第二章《失名星城》

**章节表层目标**：让无法修改姓名和出城许可的人恢复离开权。

**章节深层问题**：一个人的过去，能否替她决定永远的未来？

#### 第一阶段：归城门廊／塞芙菈

- **入口**：城门敞开，却没有离城记录；记录官维蕾娜以投影指引玩家所选主角。
- **必见线索**：巡卫每次“送回家”的终点仍是城内的第一道门。
- **Boss 原始职责**：塞芙菈护送难民，后来将“不能遗失任何人”扭曲为“不能允许任何人离开”。
- **战后**：护送路线重新指向城外，塞芙菈理解自己曾经的使命。

#### 第二阶段：藏名书馆／维蕾娜

- **入口**：记忆馆中的书页会重新排列，维蕾娜的个人意识逐渐被归档协议覆盖。
- **必见线索**：有人在灾难后加上“未经批准，不得修改登记内容”的限制。维蕾娜承认自己参与过相关修订。
- **Boss 原始职责**：保护走散者的名字；被控制时变成拒绝一切新的选择。
- **战前**：维蕾娜清醒片刻请求主角打断命令：“如果我的声音要求你留下，请不要听它。”
- **战后**：维蕾娜获得恢复规则的权力，而不是被永久杀死。她将曾经写下的错误留在档案中，以后可以修正。

#### 第三阶段：无名星穹／无名录仪

- **入口**：穹顶中无数记录将不同未来折回昨日，整座城市好像从未真正迎来第二天。
- **必见线索**：归档系统必须允许记录拥有者终止、修改或拒绝，否则“保存”只是删除未来。
- **Boss 核心诱惑**：“交还今天的名字，就归还从前的归处。”三名主角以不同理由拒绝交出今天建立的新自我。
- **战后**：强制归档终止，仍愿保留的记忆可以继续保存，其他居民可以自由离开。维蕾娜留下处理城市的新秩序。
- **结局**：星城首次出现空白的、允许后人自己填写的离城登记；玩家与归来者讨论“被记住”和“被理解”之间的区别。

#### 可选第四阶段：未署名档案／BossRush

- **地图与风险**：沿用第一章第四阶段的双倍地图、精英替换、最终连战和材料风险机制。
- **叙事内容**：三个旧日角色影像并非本人重新受困，而是档案系统对当年“护送、归档、留名”的极端测试。
- **新增悬念**：伊莉丝曾经接入的撤离信标与回廊相似，但档案末尾有一行被人主动留空的“退出权”——这不自动证明伊莉丝救世或有罪，只说明有人曾尝试阻止命令永恒化。
- **胜利后**：带回一段无法还原姓名的远航坐标，作为未来章节线索；不预定第三章的完整故事。

## 5. 营地剧情与恋爱系统：从数字解锁升级为人物关系

### 5.1 关系阶段（门槛沿用旧系统作为起始建议）

| 关系阶段 | 好感参考 | 主旨 | 可用事件 | 玩家能做什么 |
|---|---:|---|---|---|
| 初识 | 0+ | 认识她真实的性格 | 初识对话 | 倾听、提问、尊重边界 |
| 信任 | 20+ | 一次成功归来后的共同经历 | 归来邀谈 | 关切或给予空间，避免只问收获 |
| 亲近 | 50+ | 她主动分享一个脆弱或私人记忆 | 专属礼物／记忆事件 | 记住细节、做出有意义的回应 |
| 心意萌芽 | 100+ | 关系从互相感谢转为互相选择 | 私人邀约／暧昧事件 | 选择友情继续或表达进一步了解的愿望 |
| 深厚羁绊 | 200+ | 稳定关系后的专属送行和回归 | 个性化送行、承诺事件 | 送行回应、公开或私密陪伴（不强制恋爱） |

关键要求：**好感数值只代表事件资格**。告白／恋爱需要明确玩家选项，并满足对应剧情与角色回应条件；不应达到100就自动确立关系。

推荐关系状态：`friendship`／`mutual_interest`／`romance`，另存关键对话选择，不以单纯数值计算感情成立。

### 5.2 伊露雅：五个事件提纲与对白样稿

**初识｜《没有风的窗》**（好感0）
- 你在回廊看见她对着窗沿调整弓弦；这里没有林风，她却坚持把方向记下来。
- 伊露雅：“你也来认路？这里只有灯，没有风。”
- 选项A「那就先记住灯的位置。」→她轻轻点头，建立愿意一起观察的印象。
- 选项B「你可以告诉我风是什么声音吗？」→她停顿后描述树叶越过湖面的声音。
- 结尾：“我下次回来，可以讲给你听。前提是你想听。”

**信任｜《未走完的路》**（20＋至少一次成功撤离）
- 她低声承认自己没有走完想走的路。
- 玩家可选择「路没有走完，你也可以休息」或「愿意给我看你的路标吗」。两项表现关心，但性格回应不同。

**亲近｜《藤纹上的小缺口》**（50＋完成林地个人线索）
- 她说弓上的一片藤纹缺口属于曾经教她射箭的人；你没有急着询问那人是否已离世。
- 她：“我一直不敢修好这道刻痕，怕连最后的线索都没了。”
- 你可以说「保存原样也可以」或「以后我们一起想办法记住」，共同确定不强迫她放下记忆的关系原则。

**心意萌芽｜《愿意回来》**（100＋第三阶段首次胜利）
- 她把一颗尚未发芽的种子交给你：“如果我走得太远……你会怪我吗？”
- 玩家选择「你有你的路，我愿意等下一次见面」进入`mutual_interest`的前置；选择「我们一直是互相记得路的朋友」保留友情并不受惩罚。
- **不能把友情选项表现为惩罚性冷淡**；她应真诚回应。

**恋爱确认｜《同一扇窗》**（高好感＋专属邀约＋主动表达）
- 有一天回廊的窗边吹来微弱的真实林风。伊露雅迟疑着将手放在窗沿，你也伸出手，却让她自己决定是否握住。
- 伊露雅：“我不会为了谁永远留在一个地方。但是……如果你愿意，我们可以一直给彼此留一条相遇的路。”
- 玩家可选择正式回应或暂缓，剧情不覆盖既有友情状态。

### 5.3 希露媞雅：五个事件提纲与对白样稿

**初识｜《灯芯的高度》**（0）
- 她检查回廊灯盏亮度，第一句话不是问你有没有带装备，而是“你累不累”。
- 你反问她是否休息过，她一时答不上来。
- **保留旧角色事件的出发准备主题，但修正所有“帽檐／帽带”为祭袍袖口／圣云发饰等符合现人设的描述。**

**信任｜《没带回来的东西》**（20＋成功撤离）
- 她出征回来，背包比出发时轻，却记住了一个陌生人的祷词。
- 希露媞雅：“我没有替她带回想要的东西。”
- 你可回应：「你愿意记住她，已经很重要。」／「你也该让自己平安回来。」

**亲近｜《未褪色的花》**（50＋记忆花条件，复用旧`memory`事件）
- 你递上记忆花。她想先把它转送给更需要的人，但终于允许自己把礼物留下。
- 希露媞雅：“原来被照顾这件事，也可以发生在我身上。”
- 花固定在她的祭袍系带或发饰旁，不出现帽带。

**心意萌芽｜《为自己祈祷》**（100＋个人剧情）
- 她在灯前为别人祈祷许久，却想不起上一次为自己祈祷的时间。
- 玩家可以提出：“那今天，把你的名字也放在祷词里。”她第一次没有拒绝。

**恋爱确认｜《灯可以熄灭》**（高好感＋主动表达）
- 回廊深夜，她本想守夜到天亮。你问她是否愿意把灯交给别人看顾。
- 希露媞雅：“我一直以为，若有谁离开了我的光，就是我不够好。”
- 你：“那我可以在黑暗里陪你一会儿。不是因为你能照亮我。”
- 她主动选择握住你的手：“今晚，我想留在这里。为了我自己，也为了你。”

### 5.4 希希芙：五个事件提纲与对白样稿

**初识｜《三声敲击》**（0）
- 她在回廊替小扣介绍名字，担心你会因为它是骸灵而害怕。
- 玩家选择先蹲下听它说完，不抢着替她介绍。
- 希希芙：“谢谢你没有喊它过来。它比较喜欢自己走。”

**信任｜《空着的椅子》**（20＋至少一次归来）
- 某次出征后幽灯暂时离去，她盯着空椅子不肯吃东西。
- 玩家可以陪她静坐，不用承诺“它一定马上回来”。
- 片刻后希希芙：“你不说‘它永远会回来’，我反而好像放心一点。”

**亲近｜《袖口的结》**（50＋伙伴线索）
- 她解释每个线结对应一个愿意与她同行的名字，也第一次问起你的名字或称呼（保持玩家可自定义／不透露的空间）。
- 她提出给你留一个**不收紧的**结，你可以同意或婉拒，均不降低好感。

**心意萌芽｜《不用签字》**（100＋第二章相关事件）
- 她拿出新契约，最后一行什么也没写。
- 希希芙：“如果我问你明天愿不愿意见我，你可以明天再回答吗？”
- 玩家回应「我希望明天也能见到你」开启`mutual_interest`，或「我会珍惜我们的友情」保留友情。

**恋爱确认｜《明天再问一次》**（高好感＋主动表达）
- 希希芙：“我还是会害怕被留下。但我已经能自己去找小扣，也能自己回家。现在，我想问你，不是因为害怕——你愿不愿意和我一起，把以后没有写下的日子过下去？”
- 玩家可以正面回应；她得到的是被平等选择，不是终于找到一份永远不会失效的束缚。

### 5.5 伊莉丝：保留已有关系线并赋予剧情意义

原有`meeting`、`return`、`truth`、`close`可作为基础：

- **初识**：解释契约者在回廊不是命令者；伊莉丝承认任何归航都有无法保证的部分。
- **归来**：你注意到伊莉丝一直等在灯旁，首次看见她也会因归来而松一口气。
- **黑晶与旧约**：提供线索与她自身曾经的行为，不直接宣称“她就是灾难制造者”。
- **未说出口的愿望**：她盼望有一天自己不必独自守着归路；此为信任发展，不强制规定浪漫性质。

### 5.6 三人的独占性与并行机制（设计决策）

初版建议**允许多人的友情线同时推进**，允许多个角色出现暧昧事件前置，但正式确立恋爱关系时默认仅允许一条已确认关系，以便避免大量难以维护的组合剧情；若将来决定支持多恋爱关系，需要专门设计角色知情同意及对话一致性，不能默默多线同时确认。

如果玩家不选择恋爱，仍应解锁相应友情结局和高好感送行。**恋爱是剧情选择，不是永久属性奖励的必选策略。**

## 6. 营地与支线的统一叙事

### 6.1 营地——不仅是交易菜单

- **姜糖**：表面精于交易，实则坚持为失踪者保留一格无主货架。玩家帮助整理这些货架，逐渐了解回廊不等于无代价安全区。
- **温阮**：不追问客人不愿讲述的失败；在这里玩家可以不谈战果，只陪远行者喝茶。
- **布琳娜**：用撤离成功带回的材料修补营地设施。她认为裂缝是“有人回来修”的证据，而不是耻辱。
- **艾莉娅**：解释生命伤痕与普通治疗的区别，在医治中强调限制，不为剧情奇迹破坏玩法难度。
- **希尔薇娅**：整理第一章晶丝样本及第二章记录格式，帮助玩家逐步证明两个地区共享旧技术。
- **闻铃**：每次成功撤离后可以加入新的歌词，而不是宣称所有人已经获得圆满结局。

### 6.2 异闻房三个旧事件的补写方向

**`letter` 未寄出的信**：信上有撤离者更改了主意的痕迹；选择带回回廊可触发小段营地补充，不强制打断主线。

**`pack` 散落的行囊**：行囊中留下刻着姓名的旧扣。玩家归来后决定是否交给姜糖的无主货架，形成小而温柔的连贯事件。

**`page` 星灯残页**：残页表面教人指路，背面却写着“愿意者方能归来”；第二章由维蕾娜指出它与城中记录许可的区别。

### 6.3 营地礼物与约会事件

- 礼物优先表达人物性格，而非纯刷数值。例：伊露雅的林地种子、希露媞雅的记忆花、希希芙的无字线结。
- 关系事件的开启应结合成功撤离、章节探索、人物事件等条件，避免大量刷礼物一天跳过完整关系弧线。
- 玩家拒绝暧昧或选择友情时，不应该触发敌意、减少战斗能力或强迫重看告白。
- 如果送礼品是本局材料制作的，则必须在**成功撤离并入库之后**才能制作赠送；战死的本局材料不会无故出现在营地。

## 7. 战败、撤离、第四阶段与恋爱叙事的衔接

### 7.1 战死时：三种视角不能混淆

1. 战斗主角倒下：用她的视角短句展现恐惧、遗憾或守护他人的念头。
2. 伊莉丝尝试将她接回：表达回廊归航的能力和限制，不抹掉失去的资源。
3. 契约者在营地等待：死亡结算后才出现可选的短安慰事件。可因好感解锁不同对话，但**不自动把死亡写成浪漫奖励事件**。

**示例：希露媞雅战败归来**
- 旁白：“她坐在灯前，掌心仍保持着最后一次施法的姿势。”
- 你可以选择：「不必现在解释。」／「要不要先喝一点水？」／「等你准备好了，再告诉我发生了什么。」
- 希露媞雅：“你没有问我带回什么。……谢谢你。”

### 7.2 第三阶段正常撤离与第四阶段继续

选择分为游戏操作和叙事解释两层：

- **成功撤离**：本局正常胜利，材料实际带回，归来角色可触发成功归航对话及对应关系事件。剧情不得视为“退缩”。
- **进入第四阶段**：契约者在回廊端作好风险准备，远行角色以自身意愿继续探索。台词清楚说明：**此前三阶段获取但尚未撤出的材料仍未安全入库；此后战死将全部损失。**
- **第四阶段完成**：可获得与“知道何时停止、也敢于面对回声”有关的剧情成就；额外奖励若需要独立落地，应保持与玩法结算分离。

**推荐关键对话：**
- 伊莉丝：“归路已经亮了。现在回来，你们带走的东西便能留下；若再往前，灯还在，却无法替你们保管尚未归来的收获。”
- 当前主角：“我知道。不是为了证明自己勇敢。只是我还有一个问题，想亲自走到尽头。”
- 玩家选择：「结束本次出征，安全撤离」／「确认风险，进入回声深处」。

### 7.3 新版叙事不强迫主角选择

虽然交互由玩家点击决定，角色对白不能写成“契约者命令我去死”。可以写成玩家与远行者共同确认已有的选择，承认她们有自主意愿。若角色面临人设冲突，可通过一句专属回复明确其继续行动的理由。

## 9. 对白写作风格规范

| 角色 | 语言特点 | 尽量避免 |
|---|---|---|
| 伊露雅 | 简短、感官细腻，常借风、叶、路表达情绪 | 随处抛出刻板精灵典故或瞬间直白表白 |
| 希露媞雅 | 温柔但有立场，祷词较克制 | 一味自我牺牲、老练调情、戴帽的过时外观 |
| 希希芙 | 有好奇心，重视名字与询问许可，紧张时停顿 | 幼态化、以占有伙伴证明爱 |
| 伊莉丝 | 说话从容但保留真实的不确定，知道风险与代价 | 无缘无故冷酷嘲笑死者或直接神谕所有真相 |
| 维蕾娜 | 清晰、精准、带书面感，逐步恢复个人情绪 | 解放后毫无责任地轻松回归 |
| 契约者（你） | 由玩家选项塑造，可温柔、克制、幽默或坦诚 | 被剧情强行规定性格、性别、外貌、独断的命令口吻 |

游戏对话选项尽量不超过三项；首次触发与回看分开，回看不重新发好感、材料或任务奖励。相同主线节点可有共用事实＋当前出征角色专属回应，但关系事件必须真正针对与契约者的交流，而不是将主线战斗视角误写成玩家与角色并肩站在 Boss 房。

## 10. 分阶段制作优先级与验收

### 第一批：叙事身份与结构统一

- 统一玩家“契约者”身份和三位可操控主角的区别。
- 检查营地对白中的“你”和关卡对白中的`player`是否指向不同叙事人物。
- 调整旧希露媞雅关系事件的帽子描写。
- 解决第一章苏醒剧情是否触发与营地引导的先后关系。
- 将剧情从固定波次改为阶段入口、探索线索和 Boss 前后触发。

### 第二批：两章主线强化

- 第一章三位 Boss 补齐原本职责、扭曲原因、战后情绪与下一段线索。
- 第二章维蕾娜的责任、受控与获释构成可见的完整弧线。
- 让第三阶段撤离与第四阶段继续的风险说明进入剧情。
- 为第四阶段 BossRush 提供残存记录的世界观解释。

### 第三批：好感与恋爱线落地

- 为伊露雅、希露媞雅、希希芙各完成至少五个关系事件（初识、信任、亲近、心意萌芽、告白／确认）。
- 新增友情持续选项，不强制所有玩家谈恋爱。
- 关系事件根据玩家选择改变后续短对白，而不仅是数值加减。
- 送行对白针对出征角色及已确认关系动态变化；不再通用希露媞雅的一句话。
- 个人关系与本局临时战斗状态分开存储。

### 测试验收

1. 三位角色均可正常游玩两章及可选第四阶段。
2. 契约者仅作为营地与叙事人物参与，无须生成独立战斗角色。
3. 每位主角的个人主线、好感剧情和恋爱结局能单独推进。
4. 不发生“出征角色就是契约者”的台词错置。
5. 不会因为选了友情、错过一份材料或战斗失败而永久卡死剧情。
6. 世界观线索按章节推进，不提前宣布未经证实的最终真相。
7. 第三阶段胜利资格不等于材料自动带回；第四阶段死亡仍执行材料清零。
8. 旧回看事件 ID、好感和剧情进度经过迁移后不丢失。
9. 回看不重复触发奖励、好感、恋爱确认或成就。
10. 多人关系并行与恋爱确认状态符合最终产品规则。

## 11. 给 Codex 的实施指令（可直接复制）

> 以《PixelRogue 世界观、章节主线与契约者关系剧情重构方案 V1.1》为叙事规格。首先检查现有 `Story`、`CampStory`、各角色故事文件、营地剧情入口、好感系统、存档状态和新四阶段地图设计。**特别注意：玩家是独立存在的契约者（无独立可操控战斗角色），三名战斗主角不是玩家化身，且玩家与三名主角有好感与未来恋爱剧情。** 不得删除玩家身份或改写为“玩家本人就是当前出征角色”。先输出原有剧情触发／状态／角色称谓对照表与迁移风险，然后分批实装。必须保留旧稳定 ID 或提供明确兼容映射；对白选项最多三项；不改变战斗数值与成功撤离材料规则。新剧情及好感事件逐个提供触发条件、是否首次、分支选项、关系变化、已读标记、回看表现和实际可运行测试结果。新增世界真相应保持“已有证据／角色相信／尚未揭晓”的区分。未经验证不得声称所有剧情已接入游戏。

## 12. 最终校订：本稿相对 V0.5 的重点变化

1. 不再删除玩家视角，而是**恢复并强化独立的契约者叙事身份**。
2. 不把角色好感视为无关支线：营地等待、成功撤离、失忆与重逢共同构成长期情感主轴。
3. 三位战斗主角都有独立个人成长与对契约者的关系线，不再只有希露媞雅得到完整关系事件。
4. 高好感不自动进入恋爱；保留友情并赋予尊重与自由的主题意义。
5. 统一“守护失控”的世界观，连接黑晶、星城、回廊和四阶段 BossRush。
6. 第一、第二章均按新地图三阶段推进，第四阶段作为自主承担风险的额外挑战。
7. 修正部分现有台词、人设与机制不一致之处，但保留剧情 ID 兼容及未证实的世界谜团。

**整部故事最重要的一句话：你并不替她们走上那条路；你所能做的是认识她们、相信她们，并让那条归路真正属于她们自己。**
