# 设计说明

## 核心循环

```
准备 3 秒 →（敌人从视野外刷新）→ 战斗 → 全清
   ↑                                    ↓
   └── 休整 30 秒 ←── 地图上的商人 ←── 三选一道具奖励
```

三条主循环的设计意图：

1. **敌人只在视野外刷新**：玩家永远看不到「凭空出现」的怪，压迫感来自「不知道从哪边来」，
   而不是被贴脸偷袭。实现见 `src/world/spawn_finder.gd`。
2. **波次之间有喘息**：清场后有奖励 + 休整，玩家有时间看道具、想构筑、跑图找商人。
   刚打完一波的紧张感有地方释放，下一波才有重新紧绷的空间。
3. **商店放在地图上而不是菜单里**：休整时玩家要真的「走过去」，地图因此有了意义；
   同时商人只在休整时开张，避免战斗中途躲进商店拖时间。

## 视野外刷怪是怎么做的

```
1. 算出相机看到的世界矩形（get_screen_center_position + 视口尺寸 / zoom）
2. 这个矩形往外扩 90 像素 —— 只有在这个范围之外的点才是候选
3. 候选点来自关卡预先算好的「可站立格子」或「空中格子」
4. 再过滤掉离玩家不到 240 像素的点，最后从「离玩家最远的 5 个点」里随机挑
5. 找不到合适的点（地图太小 / 玩家在地图角落）时退化为「离玩家最远」
```

地面单位（游荡者、冲锋兵）挑可站立格子，空中单位（浮游灵）挑没有地面的空中格子。

## 属性与道具构筑

所有道具都只是往属性表里加「加法」或「乘法」：

```
最终值 = (基础值 + 所有加法) * (1 + 所有乘法)
```

例如「铁剑」是 `{attack: +6}`，「磨刀石」是 `{attack: +18%}`，
两件一起拿就是 `(14 + 6) * 1.18 = 23.6`。见 `src/data/stats.gd` 与 `src/data/item_db.gd`。

特殊效果（吸血、反伤、暴击、二段跳）也走同一张表，只是由战斗代码去读：
`Combat.roll_attack()` 处理暴击，`Player.take_damage()` 处理反伤，命中时处理吸血。

## 开发中发现并修掉的两个真问题

记在这里是因为它们很典型，以后加内容时容易再踩：

**1. 玩家站在敌人够不到的高台上，这一波永远打不完。**
自动试玩跑出来的：机器人躲在平台上，地面的敌人只能跳 53 px，够不到 128 px 高的平台，
双方僵住，波次永远不结束。
解决：加「暴怒」机制 —— 战斗中超过 10 秒没有击杀，剩下的敌人集体提速 50%、
跳跃力提到 730（约 177 px，足够爬上 4 格高台），并且变红提示玩家。见 `wave_director.gd` 的 `_tick_pressure()`。
这比给敌人写寻路便宜得多，而且本身就是波次游戏该有的「加压」设计。

**2. 敌人站在悬空平台正下方时，往上跳会被平台底面顶住。**
这是横版跳跃的经典问题。解决：把悬空平台（长度 ≥3 格、且不是地面/墙体）改成
**单向碰撞**（`one_way_collision`）—— 从下面可以跳穿，从上面站得住，
和马里奥的处理方式一致，手感和关卡结构都更自由。见 `level.gd` 的 `_is_one_way()`。

## 关于中文字体

Godot 自带字体不含汉字，Label 直接写中文会显示成方块。
这里用 `SystemFont`（见 `ui_factory.gd`）直接调用系统已装字体，
不把字体文件打包进项目，所以没有字体授权问题。
如果以后要在没装中文字体的机器/手机上跑，需要换成随包携带的开源字体（如思源黑体）。

## 下一步的优先级建议

| 优先级 | 做什么 | 为什么 |
|---|---|---|
| 高 | 手机触屏摇杆 + 安全区 + Android 导出 | 你最初的目标就是 PC + 移动双端，越早适配越好 |
| 高 | 音效与打击音 | 手感提升最便宜的一步（命中音、跳跃音、受伤音） |
| 中 | 换美术素材 | 玩法已经验证过，此时投入美术才不会白做 |
| 中 | Boss 波（每 5 波一个） | 给长局一个节奏锚点 |
| 低 | 层数 / 房间拼接 | 现在的固定竞技场够撑到「确认好玩」为止 |
