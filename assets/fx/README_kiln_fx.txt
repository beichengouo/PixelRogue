KILN FX - FREE SAMPLER
======================

10 effects from KILN FX - Retro Pixel VFX Megapack, each in 2 colour themes
and 2 sizes (L and S), as horizontal sprite strips:
<effect>_<theme>_<size>_strip<frames>.png  (frame width = strip width / frames)

Designed for 15 fps. Effects ending in _loop loop seamlessly.
For crisp pixels use nearest / point filtering in your engine.

The full pack has 110 effects, 799 colour variants, 2 sizes,
Godot 4 SpriteFrames and a JSON manifest. Find it on the same itch.io creator page.
